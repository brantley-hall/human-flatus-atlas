# Deploy this repository

This repository, `brantley-hall/human-flatus-atlas`, contains a static HTML site on the `main` branch. To publish it with GitHub Pages:

1. Open the repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set the branch to **main** and the folder to **/(root)**, then save.
4. Watch the Pages deployment in the repository's **Actions** tab or check the Pages settings for its status.
5. After deployment succeeds, visit `https://brantley-hall.github.io/human-flatus-atlas/`.

The repository is public and `index.html`, the other site pages, and `knowledge-base/` are at or beneath the repository root. No FTP upload, separate build step, custom server, or file-size estimate is needed for this setup. If repository settings show a custom domain, use that address instead.

## Check the published site

- Open the homepage and follow its archive and interview links.
- Confirm that the images and other files load from `knowledge-base/`.
- If a change is not visible yet, confirm the latest Pages deployment succeeded and allow a few minutes for publishing and caching.
